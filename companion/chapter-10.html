10  Nonparametric Tests

This chapter runs the five nonparametric tests from Chapter 10 of the textbook: the Wilcoxon signed-rank test, the Mann-Whitney U test, the Kruskal-Wallis test, Spearman’s rho, and Fisher’s exact test. All five are built into R, so there are no packages to load. Report the medians and the effect size alongside each test, since the test alone does not show which group is higher or by how much, so every section starts with them.

Get the script: Download the Chapter 10 script, chapter_10.R, and save it in the same folder as your data.

10.1 The data

This chapter uses two datasets. Download both into the same folder as the script:

  • Download weight_loss_incentive.csv, the weight loss experiment from Chapter 3.
  • Download census_at_school.csv, the high school survey from Chapter 1.

The variables used in this chapter:

Variables used in this chapter

WeightLoss weight_loss_incentive.csv Net weight change at the end of the 4-month treatment period (baseline weight minus month 4 weight, in pounds). Positive values indicate weight loss.

10.2 Wilcoxon signed-rank test

The question: did participants keep their weight off between month 4 and month 7? Each participant has both measurements, so they are paired.

Some participants are missing one of the two measurements. Keep only the people with both, so the medians and the test use the same people:

# CHANGE THIS: the file name of your dataset, inside the quotes.
weight <- read.csv("weight_loss_incentive.csv")
# 1. WILCOXON SIGNED-RANK test.
#    Keep only the people with BOTH measurements, using subset()
#    from Chapter 3. !is.na() means "is not missing", and & means
#    "and".
# CHANGE THIS: your dataset and your two paired measurements
pairs <- subset(weight, !is.na(WeightLoss) & !is.na(Month7Loss))
nrow(pairs)
[1] 32

32 participants have both measurements. Then the medians:

# The descriptive statistics: each measurement's median and the
# median of the differences (first minus second).
# CHANGE THIS: your two paired measurements
median(pairs$WeightLoss)
[1] 7.5
median(pairs$Month7Loss)
[1] 6
median(pairs$WeightLoss - pairs$Month7Loss)
[1] 4.75

The median weight loss was 7.5 pounds at month 4 and 6 pounds at month 7, and the median difference (month 4 minus month 7) was 4.75 pounds. Then the test, with paired = TRUE:

# The test.
#    paired = TRUE pairs the two measurements row by row.
#    exact = FALSE makes R use the normal approximation, which
#      the effect size below needs. correct = FALSE matches the
#      textbook's results. Leave them as they are.
#    The second line prints the saved result.
# CHANGE THIS: your two paired measurements, in the same order as
#              above, and a name for the result
weight_test <- wilcox.test(pairs$WeightLoss, pairs$Month7Loss,
                           paired = TRUE, exact = FALSE,
                           correct = FALSE)
weight_test

    Wilcoxon signed rank test

data:  pairs$WeightLoss and pairs$Month7Loss
V = 311, p-value = 0.3794
alternative hypothesis: true location shift is not equal to 0
Where each Wilcoxon value appears in R’s output
What you report Where it is in the output In this example
Test statistic, \(W\) V 311
p-value p-value .379
Effect size, \(r\) calculated below .16

The p-value is far above .05, so the difference between month 4 and month 7 is not statistically significant.

R does not print the effect size, Rosenthal’s \(r\). These lines calculate it from the p-value, with \(n\) as the number of pairs:

# The effect size, Rosenthal's r (R does not print it).
#    qnorm() turns the test's p-value back into its z-value.
#    abs() drops the minus sign; sqrt() is the square root.
# Copy these lines as they are; change only the result's name and
# n, the number of pairs.
z <- qnorm(weight_test$p.value / 2)
n <- 32
abs(z) / sqrt(n)
[1] 0.1553976

\(r = .16\), a small effect.

TipWith your own data

Change the dataset and the two measurements in subset(), the median() lines, and wilcox.test(), then the result’s name and n in the effect size lines. Keep the two measurements in the same order everywhere, so the differences all subtract the same way.

10.3 Mann-Whitney U test

The question: do female and male students send different numbers of texts? Text counts are very skewed (most students send a few dozen a day, and one reported 1,000), so the medians tell the story better than the means.

# CHANGE THIS: the file name of your dataset, inside the quotes.
students <- read.csv("census_at_school.csv")
# 2. MANN-WHITNEY U test.
#    Each group's median, with tapply() from Chapter 3.
# CHANGE THIS: your numerical variable and your group variable
tapply(students$TextsSent, students$Gender, median)
Female   Male 
    30     20 
#    The test is written like t.test(): the numerical variable
#    before the ~, the group variable after it. The other
#    settings work as in the Wilcoxon test above.
# CHANGE THIS: your numerical variable, your group variable,
#              your dataset, and a name for the result
texts_test <- wilcox.test(TextsSent ~ Gender, data = students,
                          exact = FALSE, correct = FALSE)
texts_test

    Wilcoxon rank sum test

data:  TextsSent by Gender
W = 38178, p-value = 1.497e-05
alternative hypothesis: true location shift is not equal to 0

The median female student sent 30 texts the previous day; the median male student sent 20. The test: \(U = 38178\), p < .001. The medians show the direction: female students sent more texts. Then the effect size, calculated the same way as for the Wilcoxon test, with \(n\) as the number of people in both groups together:

# The effect size, Rosenthal's r, the same way as above.
# Copy these lines as they are; change only the result's name and
# n, the number of people in both groups together.
z <- qnorm(texts_test$p.value / 2)
n <- 500
abs(z) / sqrt(n)
[1] 0.1936068

\(r = .19\), a small effect: the difference is real, but the two groups overlap a great deal.

NoteR calls it W

R labels the statistic W, but its value is the \(U\) statistic that the textbook reports. As the textbook explains, different programs use different labels for this test’s statistic.

WarningCommon error: grouping factor must have exactly 2 levels

What you see

wilcox.test(TextsSent ~ GetToSchool, data = students)
Error in `wilcox.test.formula()`:
! grouping factor must have exactly 2 levels

What it means: GetToSchool has three groups, and the Mann-Whitney test compares exactly two.

How to fix it: for three or more groups, use the Kruskal-Wallis test below. To compare just two of the groups, keep those two with subset() and %in%, as in Chapter 6.

TipWith your own data

Change the numerical variable, the group variable, and the dataset in both lines, then the result’s name and n in the effect size lines.

10.4 Kruskal-Wallis test

The question: do students who feel different amounts of school pressure spend different amounts of time on homework? First put the groups in order, as in Chapter 6, and look at each group’s size and median:

# 3. KRUSKAL-WALLIS test.
#    Put the groups in order, as in Chapter 6.
# CHANGE THIS: your group variable (in both places) and your
#              groups, in order
students$SchoolPressure <- factor(students$SchoolPressure,
  levels = c("None", "Very little", "Some", "A lot"))

#    Each group's size and median.
# CHANGE THIS: your numerical variable and your group variable
table(students$SchoolPressure)

       None Very little        Some       A lot 
         26         100         241         133 
tapply(students$HWHours, students$SchoolPressure, median)
       None Very little        Some       A lot 
       0.25        2.00        5.00        5.00

The medians rise from 0.25 hours a week for students who feel no pressure to 5 hours for those who feel some or a lot. Then the test:

# The test, written like aov() in Chapter 6.
# CHANGE THIS: your numerical variable, your group variable,
#              your dataset, and a name for the result
pressure_test <- kruskal.test(HWHours ~ SchoolPressure,
                              data = students)
pressure_test

    Kruskal-Wallis rank sum test

data:  HWHours by SchoolPressure
Kruskal-Wallis chi-squared = 101.29, df = 3, p-value <
2.2e-16

R labels the \(H\) statistic Kruskal-Wallis chi-squared, and it is the version adjusted for ties (students with the same value share a rank, and the adjustment accounts for that sharing): \(H(3) = 101.29\), p < .001. Homework time differs across the pressure groups.

R does not print the effect size, epsilon-squared. These lines calculate it from \(H\):

# The effect size, epsilon-squared (R does not print it).
#    $statistic picks out H from the test's results.
# Copy these lines as they are; change only the result's name and
# n, the number of people with both values.
n <- 500
pressure_test$statistic / (n - 1)
Kruskal-Wallis chi-squared 
                 0.2029805

\(\varepsilon^2 = 0.20\), a large effect: the pressure groups account for about 20% of the variation in homework-time ranks. R prints the label Kruskal-Wallis chi-squared above the number because the value came from that part of the results; the number itself is \(\varepsilon^2\).

TipWith your own data

Change the group variable and its groups in factor(), then the numerical variable, the group variable, and the dataset in table(), tapply(), and kruskal.test(), and the result’s name and n in the effect size lines.

10.5 Spearman’s rho

Spearman’s rho works for an ordered categorical variable, such as school pressure, because it uses only the ranks. Unlike Kruskal-Wallis, which treats the groups as separate buckets, it uses their order, which gives it more power. To use the groups in a correlation, first turn them into ranks with as.integer(), which gives each group its place in the order you set. Then run cor.test() from Chapter 4 with method = "spearman":

# 4. SPEARMAN'S RHO.
#    For an ordered categorical variable, first turn its groups
#    into ranks: as.integer() gives each group its place in the
#    order set above (None = 1, Very little = 2, Some = 3,
#    A lot = 4). Skip this line if both variables are numerical.
# CHANGE THIS: your ordered variable and a name for its ranks
students$PressureRank <- as.integer(students$SchoolPressure)

#    method = "spearman" makes cor.test() from Chapter 4 calculate
#      Spearman's rho instead of Pearson's r.
#    exact = FALSE is needed when values are tied, as they almost
#      always are. Leave it as is.
# CHANGE THIS: your two variables, and a name for the result
pressure_rho <- cor.test(students$HWHours, students$PressureRank,
                         method = "spearman", exact = FALSE)
pressure_rho

    Spearman's rank correlation rho

data:  students$HWHours and students$PressureRank
S = 12529669, p-value < 2.2e-16
alternative hypothesis: true rho is not equal to 0
sample estimates:
      rho 
0.3985735

\(r_s = .40\), p < .001: students who feel more school pressure tend to spend more time on homework. Ignore the S statistic; it is a step in calculating the p-value, while \(r_s\) is the number your reader can interpret.

R does not print a confidence interval for Spearman’s rho. These three lines calculate one with the usual method (Fisher’s \(z\) transformation):

# The 95% confidence interval for rho (R does not print one).
# Copy these lines as they are; change only the result's name and
# n, the number of people with both values (with no missing
# values, the number of rows in your dataset).
rho <- pressure_rho$estimate
n <- 500
tanh(atanh(rho) + c(-1.96, 1.96) / sqrt(n - 3))
[1] 0.3221407 0.4698438

The 95% CI is [.32, .47].

TipWith your own data

If both of your variables are numerical, skip the as.integer() line and put your two variables straight into cor.test(). If one is an ordered categorical variable, set its order with factor() first, so the ranks go from lowest to highest.

10.6 Fisher’s exact test

Chapter 8 of this companion showed that the chi-square test for gender and travel to school gives the warning Chi-squared approximation may be incorrect, because few students walk. Fisher’s exact test handles small expected counts, because it has no minimum expected count:

# 5. FISHER'S EXACT test, for a cross-tabulation with expected
#    counts below 5 (see Chapter 8).
#    Row proportions first, as in Chapter 2, to see the pattern.
# CHANGE THIS: your two categorical variables
travel_table <- table(students$Gender, students$GetToSchool)
travel_table
        
         Bus Car Walk
  Female  20 236    4
  Male    35 202    3
round(prop.table(travel_table, margin = 1), 3)
        
           Bus   Car  Walk
  Female 0.077 0.908 0.015
  Male   0.146 0.842 0.013
# The test needs only the table.
# CHANGE THIS: your table's name
fisher.test(travel_table)

    Fisher's Exact Test for Count Data

data:  travel_table
p-value = 0.04274
alternative hypothesis: two.sided

Fisher’s exact test has no test statistic, so report the proportions and the p-value: 14.6% of male students and 7.7% of female students take the bus to school, and the test finds the travel pattern differs by gender, p = .043.

TipWith your own data

Change the two variables in table(). fisher.test() works on a 2 × 2 table or a larger one, as here.
