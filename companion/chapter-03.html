3  t-Tests, Effect Sizes, and Power

This chapter runs the three t-tests from Chapter 3 of the textbook (single sample, matched pair, and Welch’s independent sample), then calculates Cohen’s d and the sample size a study needs for 80% power. Along the way you will learn to keep only one group’s rows, which you need whenever a question is about one group.

Get the script: Download the Chapter 3 script, chapter_03.R, and save it in the same folder as your data.

3.1 The data

This chapter uses two datasets. Download both into the same folder as the script:

  • Download census_at_school.csv, the high school survey from Chapter 1.
  • Download weight_loss_incentive.csv, a randomized experiment with 38 participants testing whether cash rewards help people lose weight.

The variables used in this chapter:

Variables used in this chapter
Variable Dataset What it records
Sleep1 census_at_school.csv The typical number of hours of sleep the student gets on a school night.
Sleep2 census_at_school.csv The typical number of hours of sleep the student gets on a non-school night (weekends/holidays).
WeightLoss weight_loss_incentive.csv Net weight change measured at the end of the active 4-month treatment period (\(\text{Baseline Weight} - \text{Month 4 Weight}\) in pounds). Positive values indicate weight loss; negative values indicate weight gain.
Group weight_loss_incentive.csv The experimental group assignment for the participant (Control or Incentive).
Month7Loss weight_loss_incentive.csv Net weight change measured at the 7-month mark, which includes a 3-month unmonitored follow-up phase (\(\text{Baseline Weight} - \text{Month 7 Weight}\) in pounds). Positive values indicate weight loss; negative values indicate weight gain.

3.2 Load the package and the data

The t-tests are built into R. Cohen’s d comes from the effectsize package; if you have not installed it yet, go back to Install and load packages in Getting Set Up.

# Load effectsize, the package that calculates Cohen's d. The
# t-tests themselves are built into R and need no package.
library(effectsize)
# CHANGE THIS: the file name of your dataset, inside the quotes.
students <- read.csv("census_at_school.csv")

Before any t-test, check the shape of your variable with a histogram (Chapter 1) to judge whether the test’s requirements are met, as the textbook describes.

3.3 Single sample t-test

A single sample t-test compares the mean of one variable to a fixed benchmark. Here the question is whether high school seniors sleep a different amount on school nights than the 8 hours often recommended for teenagers.

# 1. SINGLE SAMPLE t-test: compares the mean of one variable to a
#    fixed number (a benchmark).
#    The first argument is the variable to test.
#    mu = 8 is the benchmark: here, 8 hours of sleep. (mu is the
#      Greek letter for a population mean.)
# CHANGE THIS: your variable after the $, and your benchmark
#              after mu =
t.test(students$Sleep1, mu = 8)

    One Sample t-test

data:  students$Sleep1
t = -23.577, df = 499, p-value < 2.2e-16
alternative hypothesis: true mean is not equal to 8
95 percent confidence interval:
 6.692417 6.893583
sample estimates:
mean of x 
    6.793

Every t-test in R prints the same layout. Here is where to find each value you report:

Where each value appears in R’s t-test output
What you report Where it is in the output In this example
t statistic t = \(-23.58\)
Degrees of freedom df = 499
p-value p-value = below .001 (see the note below)
95% confidence interval the two numbers under 95 percent confidence interval [6.69, 6.89]
Sample mean under sample estimates 6.79 hours

The line alternative hypothesis: true mean is not equal to 8 confirms R ran the two-sided test, with \(H_1\) using \(\neq\), so the test can find an effect in either direction. R does this unless you tell it otherwise, so leave that setting alone.

NoteReading p-value < 2.2e-16

2.2e-16 is R’s way of writing a very small number: move the decimal point 16 places to the left, so 0.00000000000000022. R does not print p-values smaller than this, so it writes < 2.2e-16 instead. In a report, write p < .001.

The same shorthand appears elsewhere: 5.9e-04 means 0.00059.

TipWith your own data

Change the variable after the $, and put your benchmark after mu =. The benchmark comes from outside your data: a published average, a clinical cutoff, or a value set before you collected the data.

3.4 Matched pair t-test

A matched pair t-test compares two measurements taken on the same people, such as before and after. Here each student reported their sleep on non-school nights (Sleep2) and on school nights (Sleep1).

# 2. MATCHED PAIR t-test: compares two measurements taken on the
#    same people. Here each student reported sleep on a
#    non-school night (Sleep2) and on a school night (Sleep1).
#    paired = TRUE tells R the two columns belong to the same
#      people, row by row.
#    R subtracts the second variable from the first, so the
#      difference here is Sleep2 minus Sleep1.
# CHANGE THIS: your two variables, in the order you want them
#              subtracted
t.test(students$Sleep2, students$Sleep1, paired = TRUE)

    Paired t-test

data:  students$Sleep2 and students$Sleep1
t = 27.467, df = 499, p-value < 2.2e-16
alternative hypothesis: true mean difference is not equal to 0
95 percent confidence interval:
 1.944218 2.243782
sample estimates:
mean difference 
          2.094

R subtracts the second variable from the first, row by row. Here that is non-school-night sleep minus school-night sleep, so the mean difference of 2.09 means students sleep about 2 hours more on non-school nights. The values to report are in the same places as before.

This is the same test as running a single sample t-test on the difference scores with mu = 0. If your dataset already has a difference column (such as a “change” variable), you can test that column with the code from the previous section instead.

TipWith your own data

Put your two measurements in the order you want them subtracted: usually the later measurement first, so a positive difference means an increase. Both variables must come from the same people, in the same rows.

3.5 Group means and standard deviations

To report two groups in APA style, you need each group’s mean and standard deviation. tapply() splits a variable by group and calculates something for each part:

# CHANGE THIS: the file name of your dataset, inside the quotes.
weight <- read.csv("weight_loss_incentive.csv")
# 3. GROUP MEANS AND STANDARD DEVIATIONS, for reporting.
#    tapply(variable, groups, function) splits the variable by
#      group and applies the function (mean or sd) to each part.
#    na.rm = TRUE skips the blank cells, as in Chapter 1.
# CHANGE THIS: your numerical variable and your group variable
#              in both lines
tapply(weight$WeightLoss, weight$Group, mean, na.rm = TRUE)
  Control Incentive 
 3.921053 15.676471 
tapply(weight$WeightLoss, weight$Group, sd, na.rm = TRUE)
  Control Incentive 
 9.107785  9.413988

The control group lost an average of 3.92 pounds and the incentive group lost 15.68 pounds.

TipWith your own data

Change the numerical variable and the group variable in both lines. The third argument is the calculation: mean, sd, or median (with no parentheses after it).

3.6 Welch’s independent sample t-test

An independent sample t-test compares the means of two separate groups. R runs Welch’s version unless you tell it otherwise. Welch’s version adjusts for groups with different spreads, so its p-value stays reliable whether or not the spreads match.

# 4. WELCH'S INDEPENDENT SAMPLE t-test: compares the means of two
#    separate groups. R uses Welch's version unless you tell it
#    otherwise.
#    WeightLoss ~ Group reads "WeightLoss, split by Group". The ~
#      sign (called a tilde) is on the top-left key of most
#      keyboards.
#    data = weight names the dataset, so you do not need $.
# CHANGE THIS: your numerical variable before the ~, your group
#              variable after it, and your dataset after data =
t.test(WeightLoss ~ Group, data = weight)

    Welch Two Sample t-test

data:  WeightLoss by Group
t = -3.7982, df = 33.276, p-value = 0.0005889
alternative hypothesis: true difference in means between group Control and group Incentive is not equal to 0
95 percent confidence interval:
 -18.05026  -5.46058
sample estimates:
  mean in group Control mean in group Incentive 
               3.921053               15.676471

The values to report are in the same places as before. Two things are new:

  • The degrees of freedom have decimals (33.28 here). That is normal for Welch’s test; report them as printed, rounded to two places.
  • The order of the groups: R puts the groups in alphabetical order (Control, then Incentive) and subtracts the second from the first. The confidence interval [\(-18.05\), \(-5.46\)] is negative because the control group lost less weight than the incentive group.

The ~ sign (called a tilde) means “split by”: WeightLoss ~ Group reads “WeightLoss, split by Group.” Because data = weight names the dataset, you do not need $.

WarningCommon error: grouping factor must have exactly 2 levels

What you see

t.test(Sleep1 ~ GetToSchool, data = students)
Error in `t.test.formula()`:
! grouping factor must have exactly 2 levels

What it means: a t-test compares exactly two groups, and GetToSchool has three (Bus, Car, and Walk).

How to fix it: keep only two groups first (see A t-test for one group only for how subset() works), or use a test built for three or more groups, the one-way ANOVA in Chapter 6.

TipWith your own data

Put your numerical variable before the ~, your group variable after it, and your dataset after data =. The group variable must have exactly two groups.

3.7 Cohen’s d

Cohen’s d measures how large the difference between the two groups is, in standard deviations. It is written the same way as the t-test:

# 5. COHEN'S d for the difference between the two groups. It is
#    written the same way as the t-test.
# CHANGE THIS: the same variables and dataset as your t-test
cohens_d(WeightLoss ~ Group, data = weight)
Warning: Missing values detected. NAs dropped.
Cohen's d |         95% CI
--------------------------
-1.27     | [-1.98, -0.54]

- Estimated using pooled SD.

Cohen’s d is \(-1.27\), a large effect by the usual rules of thumb (about 0.2 is small, 0.5 medium, and 0.8 large). As with the t-test, the sign only reflects the alphabetical order of the groups; judge the size from the number without its minus sign. The line Estimated using pooled SD means the standard deviation combines both groups, so the difference is measured against the spread of everyone in the study.

NoteWarning: Missing values detected. NAs dropped.

Two participants have a blank WeightLoss, so cohens_d() leaves them out and says so. The t-test leaves them out too, without saying anything.

TipWith your own data

Copy the variables and dataset from your t.test() line.

3.8 A t-test for one group only

Some questions are about one group: for example, whether the incentive group kept the weight off at the 7-month follow-up. First keep only that group’s rows with subset(), then test the smaller dataset.

# 6. A t-test FOR ONE GROUP ONLY.
#    subset() keeps only the rows that match a condition.
#    Group == "Incentive" means "Group is exactly Incentive". Use
#      two equals signs, and spell the group exactly as it appears
#      in the data, inside quotes.
#    The result is stored as a new, smaller dataset.
# CHANGE THIS: your dataset, your group variable, and the group
#              you want to keep
incentive <- subset(weight, Group == "Incentive")
nrow(incentive)
[1] 19
# Then test that group's Month7Loss against 0 (no change).
# CHANGE THIS: your variable after the $, and your benchmark
t.test(incentive$Month7Loss, mu = 0)

    One Sample t-test

data:  incentive$Month7Loss
t = 2.5054, df = 14, p-value = 0.0252
alternative hypothesis: true mean is not equal to 0
95 percent confidence interval:
  1.122724 14.477276
sample estimates:
mean of x 
      7.8

The new dataset incentive has 19 rows, one per participant in the incentive group. They were still about 7.8 pounds lighter than at the start of the study, 95% CI [1.12, 14.48]. The degrees of freedom are 14, not 18, because 4 of these participants have a blank Month7Loss.

WarningCommon error: extra argument will be disregarded

What you see

wrong <- subset(weight, Group = "Incentive")
Warning: In subset.data.frame(weight, Group = "Incentive") :
 extra argument 'Group' will be disregarded
nrow(wrong)
[1] 38

What it means: with one equals sign, R does not compare anything. It ignores the condition and keeps all 38 rows, so any test on wrong uses both groups.

How to fix it: use two equals signs, ==, which means “is exactly.”

WarningCommon error: not enough ‘x’ observations

What you see

wrong <- subset(weight, Group == "incentive")
nrow(wrong)
[1] 0
t.test(wrong$Month7Loss, mu = 0)
Error in `t.test.default()`:
! not enough 'x' observations

What it means: no rows matched, so the new dataset is empty (0 rows) and there is nothing to test. The group is spelled Incentive, with a capital I.

How to fix it: copy the group name exactly as it appears in the data. To see the spellings, run table(weight$Group).

TipWith your own data

Change the dataset, the group variable, and the group name (inside quotes). Run nrow() on the result to check that the number of rows makes sense before you run the test.

3.9 Sample size for a power of 80%

Before a study, a power analysis tells you how many participants you need. power.t.test() takes everything except the sample size and fills in the one value you leave out:

# 7. SAMPLE SIZE FOR 80% POWER (independent sample t-test).
#    delta = 0.5 is the effect size you expect, as a Cohen's d.
#    sd = 1 lets delta be read as a Cohen's d. Leave it at 1.
#    sig.level = 0.05 is the significance level (alpha).
#    power = 0.80 is the power you want.
#    R fills in the one value you leave out: here, n.
# CHANGE THIS: the effect size you expect, after delta =
power.t.test(delta = 0.5, sd = 1, sig.level = 0.05, power = 0.80)

     Two-sample t test power calculation 

              n = 63.76576
          delta = 0.5
             sd = 1
      sig.level = 0.05
          power = 0.8
    alternative = two.sided

NOTE: n is number in *each* group

To detect a medium effect (\(d = 0.5\)) with 80% power at \(\alpha = .05\), you need 63.77 participants in each group. Always round up: 64 per group, or 128 in total. The note at the bottom is a reminder that n counts one group, not the whole study.

TipWith your own data

Put the effect size you expect after delta =, as a Cohen’s d from past research or from the smallest effect that would matter in practice. If you know the effect in your variable’s own units instead (for example, a 4-point drop on a scale with a standard deviation of 11.5), put the raw difference after delta = and the standard deviation after sd =.
