8  Categorical Data Analysis

This chapter runs the categorical tests from Chapter 8 of the textbook: the chi-square goodness-of-fit test, the test for independence (and its twin, the test for homogeneity), McNemar’s test, and the three ways the textbook measures a categorical relationship: Cramér’s V, relative risk with the odds ratio, and sensitivity with specificity. Most of it uses two functions built into R, table() and chisq.test().

Get the script: Download the Chapter 8 script, chapter_08.R, and save it in the same folder as your data.

8.1 The data

This chapter uses three datasets. Download all three into the same folder as the script:

  • Download census_at_school.csv, the high school survey from Chapter 1.
  • Download acs_2023.csv, the American Community Survey data from Chapter 5.
  • Download smoking_bmi_bp.csv, the blood pressure data from Chapter 6.

The variables used in this chapter:

Variables used in this chapter
Variable Dataset What it records
Season census_at_school.csv The student’s favorite season, stored in the file as Fall, Spring, Summer, or Winter.
Gender census_at_school.csv The individual’s gender (Female or Male).
Superpower census_at_school.csv The superpower the student desires most (Fly, Freeze time, Invisibility, Super strength, or Telepathy).
Sleep1, Sleep2 census_at_school.csv The typical number of hours of sleep the student gets on a school night (Sleep1) and on a non-school night (Sleep2).

8.2 Load the package and the data

This chapter uses the effectsize package for Cramér’s V. If you have not installed it yet, go back to Install and load packages in Getting Set Up.

# effectsize calculates Cramer's V. Everything else in this
# chapter is built into R.
library(effectsize)
# CHANGE THIS: the file name of your dataset, inside the quotes.
students <- read.csv("census_at_school.csv")

8.3 Goodness-of-fit test

The question: are all four seasons equally popular as students’ favorite? A goodness-of-fit test compares the counts in one categorical variable to a set of expected proportions. Count the categories with table(), then give chisq.test() the proportions you expect:

# 1. GOODNESS-OF-FIT: does one categorical variable match a set of
#    expected proportions?
#    table() counts each category, in alphabetical order.
# CHANGE THIS: your categorical variable
season_counts <- table(students$Season)
season_counts

  Fall Spring Summer Winter 
   182     65    179     74 
#    p = c(...) lists the expected proportion for each category,
#      as decimals, in the SAME order as the table above. They
#      must add up to 1. Here every season is expected to be
#      equally popular (0.25 each).
# CHANGE THIS: the table name and your expected proportions
season_test <- chisq.test(season_counts,
                          p = c(0.25, 0.25, 0.25, 0.25))
season_test

    Chi-squared test for given probabilities

data:  season_counts
X-squared = 98.928, df = 3, p-value < 2.2e-16

The proportions after p = must be in the same order as the categories in the table, which R puts in alphabetical order (Fall, Spring, Summer, Winter). Here every season gets 0.25. With a published baseline, such as the Census proportions in the textbook, you would type those proportions instead.

The result: \(\chi^2(3, N = 500) = 98.93\), p < .001. The df in the output is the degrees of freedom, and N is the total of the counts. The seasons are not equally popular.

WarningCommon error: probabilities must sum to 1

What you see

chisq.test(season_counts, p = c(0.25, 0.25, 0.25, 0.20))
Error in `chisq.test()`:
! probabilities must sum to 1.

What it means: the proportions after p = add up to 0.95, not 1.

How to fix it: check your proportions and make sure they add up to exactly 1. If they come from a published source and only miss 1 because of rounding, add rescale.p = TRUE inside chisq.test(), as the textbook’s code does, and R scales them up to 1 for you.

8.3.1 Expected counts and standardized residuals

Two more pieces of the test’s results finish the analysis:

# The expected counts (check that each one is at least 5) and the
# standardized residuals, rounded to 2 decimal places.
#    $stdres holds the standardized residuals. Use $stdres, not
#      $residuals, which holds a different kind of residual.
# CHANGE THIS: your test's name, in both lines
season_test$expected
  Fall Spring Summer Winter 
   125    125    125    125 
round(season_test$stdres, 2)

  Fall Spring Summer Winter 
  5.89  -6.20   5.58  -5.27
  • $expected gives the expected counts. Every one must be at least 5, the usual rule of thumb; below 5, the p-value is no longer trustworthy. Here each is 125.
  • $stdres gives the standardized residuals, which work like z-scores. A common rule of thumb flags any value outside \(-2\) to \(+2\). Fall (5.89) and Summer (5.58) are chosen more often than expected, and Spring (\(-6.20\)) and Winter (\(-5.27\)) less often.

The $ works here the same way it does for a dataset: it picks out one part of the test’s results by name.

WarningCheck: $stdres, not $residuals

The results also include $residuals, which R prints without any warning. These are a different kind of residual, and they come out smaller than the standardized residuals (here, Fall would be 5.10 instead of 5.89), so the \(\pm 2\) rule does not apply to them. Always use $stdres.

TipWith your own data

Change the variable inside table(), then list one expected proportion for each category in alphabetical order. Use table() first to see the order R uses, and count the categories so the list has one proportion per category.

8.4 Test for independence

The question: are gender and desired superpower related? Build the cross-tabulation with table(), putting one variable in the rows and the other in the columns. Row proportions, from Chapter 2, make the rows easier to compare:

# 2. test FOR INDEPENDENCE: are two categorical variables related?
#    table(rows, columns) builds the cross-tabulation.
#    prop.table(..., margin = 1) turns each row into proportions,
#      as in Chapter 2, so the rows can be compared.
# CHANGE THIS: your two categorical variables
power_table <- table(students$Gender, students$Superpower)
power_table
        
         Fly Freeze time Invisibility Super strength Telepathy
  Female  69          62           49              4        76
  Male    51          81           33             31        44
round(prop.table(power_table, margin = 1), 2)
        
          Fly Freeze time Invisibility Super strength Telepathy
  Female 0.27        0.24         0.19           0.02      0.29
  Male   0.21        0.34         0.14           0.13      0.18
# The test. With a cross-tabulation, chisq.test() needs nothing
# else: it calculates the expected counts itself.
# CHANGE THIS: your table's name, and a name for the test
power_test <- chisq.test(power_table)
power_test

    Pearson's Chi-squared test

data:  power_table
X-squared = 36.967, df = 4, p-value = 1.829e-07

Super strength stands out: 13% of male students chose it, compared with 2% of female students. The test: \(\chi^2(4, N = 500) = 36.97\), p < .001, so gender and desired superpower are related.

# Expected counts and standardized residuals for every cell.
# round(..., 1) rounds to 1 decimal place.
# CHANGE THIS: your test's name, in both lines
round(power_test$expected, 1)
        
          Fly Freeze time Invisibility Super strength Telepathy
  Female 62.4        74.4         42.6           18.2      62.4
  Male   57.6        68.6         39.4           16.8      57.6
round(power_test$stdres, 2)
        
           Fly Freeze time Invisibility Super strength Telepathy
  Female  1.38       -2.45         1.54          -4.98      2.85
  Male   -1.38        2.45        -1.54           4.98     -2.85

Every expected count is at least 5 (the smallest is 16.8), so the assumption holds. Three columns have standardized residuals outside \(-2\) to \(+2\). Male students chose Super strength (4.98) and Freeze time (2.45) more often than expected, and Telepathy less often (\(-2.85\)); female students show the opposite pattern. Fly and Invisibility fall inside the range. With two rows, each cell’s residual is the exact opposite of the one below it, so reading one row is enough.

NoteThe test for homogeneity uses the same code

The textbook’s test for homogeneity differs from the test for independence in the study design (how the data were collected), not the calculations. In R, both use exactly the same table() and chisq.test() lines. Put the populations you are comparing in the rows.

WarningCommon error: Chi-squared approximation may be incorrect

What you see

chisq.test(table(students$Gender, students$GetToSchool))
Warning in chisq.test(table(students$Gender,
students$GetToSchool)): Chi-squared approximation may be incorrect

    Pearson's Chi-squared test

data:  table(students$Gender, students$GetToSchool)
X-squared = 6.0828, df = 2, p-value = 0.04777

What it means: this is a warning, not an error, so R still prints a result. It means at least one expected count is below 5 (here, very few students walk to school), so the p-value cannot be trusted. Check with $expected to see which cells are too small.

How to fix it: do not report this p-value. You have two options: combine small categories into larger, meaningful ones (as the textbook does with the armed variable), or use Fisher’s Exact Test from Chapter 10, which has no minimum expected count.

8.4.1 Cramér’s V

cramers_v() measures the strength of the relationship:

# CRAMER'S V, from the effectsize package.
#    adjust = FALSE gives the standard Cramer's V, the version the
#    cutoffs in the textbook's Table 8.3 are for. (Leaving it out
#    gives a slightly smaller, bias-adjusted version.)
# CHANGE THIS: your table's name
cramers_v(power_table, adjust = FALSE)
Cramer's V |       95% CI
-------------------------
0.27       | [0.18, 1.00]

- One-sided CIs: upper bound fixed at [1.00].

\(V = 0.27\). Cramér’s V cutoffs depend on the size of the table, because more categories spread the data out. Find the row for the number of categories in the smaller variable:

Cutoffs for Cramér’s V (Table 8.3 in the textbook)
Categories in the smaller variable Small Medium Large
2 (same as Phi) 0.10 0.30 0.50
3 0.07 0.21 0.35
4 0.06 0.17 0.29
5 0.05 0.15 0.25

Gender has 2 categories, so use the first row: 0.27 is above the 0.10 cutoff for a small effect but below the 0.30 cutoff for a medium effect, so the association is small. The 95% CI is a range of likely values; its upper end is always printed as 1.00, and the note under the table says so. You can ignore it.

TipWith your own data

Put your two categorical variables inside table(), then change the table name in chisq.test() and cramers_v(). Count the categories in each variable, and use the smaller count to pick the row of the cutoff table above. For a 2 × 2 table, the same function gives Phi.

8.5 McNemar’s test

McNemar’s test is for paired yes/no answers: the same people, two times or two questions. The question here: is the share of students who sleep at least 8 hours different on school nights and non-school nights?

The data hold hours of sleep, not yes/no answers, so the first two lines create the yes/no columns with ifelse(). If your data already have two yes/no columns, skip those lines.

# 3. McNEMAR'S test: the same people answer two yes/no questions.
#    Here the two "questions" are whether each student sleeps at
#    least 8 hours on a school night and on a non-school night.
#    ifelse(test, "Yes", "No") gives "Yes" for each row where the
#      test is true, and "No" where it is false.
# CHANGE THIS: your variables, your cutoff, and new column names.
#              (If your data already hold two yes/no columns,
#              skip these two lines.)
students$Enough1 <- ifelse(students$Sleep1 >= 8, "Yes", "No")
students$Enough2 <- ifelse(students$Sleep2 >= 8, "Yes", "No")

#    Inside table(), Name = column gives each side a label.
# CHANGE THIS: your labels and your two yes/no columns
sleep_table <- table(SchoolNight = students$Enough1,
                     NonSchoolNight = students$Enough2)
sleep_table
           NonSchoolNight
SchoolNight  No Yes
        No   53 332
        Yes  10 105
mcnemar.test(sleep_table)

    McNemar's Chi-squared test with continuity correction

data:  sleep_table
McNemar's chi-squared = 301.29, df = 1, p-value < 2.2e-16

The two disagreement cells are what the test compares: 332 students sleep 8 hours or more only on non-school nights, and 10 only on school nights. \(\chi^2(1, N = 500) = 301.29\), p < .001, so students are much more likely to reach 8 hours on non-school nights. As the textbook says, no post hoc test is needed: compare those two cells to see which way the difference goes.

NoteContinuity correction

The output’s title says “with continuity correction.” That is a small adjustment R makes by default for a 2 × 2 table, where the chi-square p-value otherwise comes out a little too small. It also matches the textbook’s results, so you do not need to change anything.

TipWith your own data

Put the two yes/no columns in table(), in the same order as they happened. The labels before each = are names for the table and can be anything.

8.6 Relative risk and the odds ratio

The question: compared with citizens, how likely are noncitizens to have health insurance? Both variables are coded 0 and 1. Put the groups you are comparing in the rows and the outcome in the columns, then turn each row into proportions, the risk of each outcome:

# CHANGE THIS: the file name of your dataset, inside the quotes.
acs <- read.csv("acs_2023.csv")
# 4. RELATIVE RISK AND THE ODDS RATIO.
#    The groups you compare go in the rows; the outcome goes in
#    the columns. Both variables here are coded 0 and 1.
# CHANGE THIS: your group variable and your outcome variable
insurance_table <- table(Citizen = acs$USCitizen,
                         Insured = acs$HealthInsurance)
insurance_table
       Insured
Citizen    0    1
      0  152  425
      1  736 8687
#    Each group's risk: the proportion in each row with each
#    outcome.
# CHANGE THIS: your table's name
risk <- prop.table(insurance_table, margin = 1)
risk
       Insured
Citizen          0          1
      0 0.26343154 0.73656846
      1 0.07810676 0.92189324

73.7% of noncitizens (row 0) and 92.2% of citizens (row 1) have health insurance (column 1).

Relative risk divides one group’s risk by the baseline group’s risk. Square brackets pick one cell: the row name first, then the column name, each in quotes.

# RELATIVE RISK: one group's risk of the outcome divided by the
# baseline group's risk.
#    risk["0", "1"] means the row named 0 (noncitizens) and the
#      column named 1 (insured). The row comes first, then the
#      column, each in quotes.
# CHANGE THIS: the row of your group, the row of your baseline
#              group, and the column of your outcome
risk["0", "1"] / risk["1", "1"]
[1] 0.7989737

The relative risk is 0.80: noncitizens are 80% as likely as citizens to have health insurance. Using the textbook’s flipping trick, \(1 / 0.80 = 1.25\): citizens are 1.25 times as likely to be insured.

The odds ratio divides one group’s odds by the baseline group’s odds. Each group’s odds is its risk of the outcome divided by its risk of not having it:

# THE ODDS RATIO.
#    Each group's odds: its risk of the outcome divided by its
#      risk of not having it. risk[, "1"] (nothing before the
#      comma) means the whole column named 1, for every row.
# CHANGE THIS: the column of your outcome first, then the other
#              column
odds <- risk[, "1"] / risk[, "0"]
odds
        0         1 
 2.796053 11.802989 
#    The odds ratio: one group's odds divided by the baseline
#    group's odds.
# CHANGE THIS: your group first, then your baseline group
odds["0"] / odds["1"]
        0 
0.2368936

The first line gives each group’s odds: about 2.8 insured noncitizens for every uninsured one, and about 11.8 for citizens. The odds ratio is 0.24 (the 0 printed above it is just the label of the group it came from).

Cohen’s effect size cutoffs have been translated to the odds ratio scale. Use the column that matches your odds ratio:

Effect size cutoffs for odds ratios (Table 8.5 in the textbook)
Effect size Odds ratio > 1.0 Odds ratio < 1.0
Small 1.50 0.67
Medium 3.50 0.29
Large 9.00 0.11

In the “Odds ratio < 1.0” column, 0.24 is beyond the 0.29 cutoff for a medium effect but not as far as 0.11 for a large one, so it is a medium effect.

WarningCommon error: subscript out of bounds

What you see

risk["No", "1"]
Error in `[.default`:
! subscript out of bounds

What it means: the table has no row called No. The row and column names must match the table exactly; here they are 0 and 1, because that is how the variables are coded.

How to fix it: look at the printed table and copy its row and column names, keeping the quotes.

TipWith your own data

Put your group variable first in table() and your outcome second. Then, in the relative risk and odds ratio lines, change the names in quotes: your group’s row, your baseline group’s row, and your outcome’s column. If your variables use words instead of 0 and 1, use those words, spelled exactly as in the table.

8.7 Sensitivity and specificity

Sensitivity and specificity describe how well a yes/no rule predicts what actually happens. In this example, the rule predicts high blood pressure for everyone in the Obese BMI group, and the outcome is a systolic reading of 140 mmHg or higher. Two ifelse() lines create the predicted and actual columns, and table() builds the confusion matrix, with the predictions in the rows:

# CHANGE THIS: the file name of your dataset, inside the quotes.
pressure <- read.csv("smoking_bmi_bp.csv")
# 5. SENSITIVITY AND SPECIFICITY of a yes/no rule.
#    The rule: predict high blood pressure for everyone in the
#      Obese BMI group.
#    What actually happened: a systolic reading of 140 mmHg or
#      higher.
#    == means "is exactly equal to" (two equals signs).
# CHANGE THIS: your rule, your outcome, and new column names
pressure$Predicted <- ifelse(pressure$BMI == "Obese", "Yes", "No")
pressure$Actual <- ifelse(pressure$SystolicBP >= 140, "Yes", "No")

# The confusion matrix: predictions in the rows, what actually
# happened in the columns.
# CHANGE THIS: your dataset name, in both places
confusion <- table(Predicted = pressure$Predicted,
                   Actual = pressure$Actual)
confusion
         Actual
Predicted  No Yes
      No  167 129
      Yes  80 124

Then divide the cells:

# SENSITIVITY: of the people who actually had the outcome, the
# proportion the rule caught.
#    sum(confusion[, "Yes"]) adds up the whole "Yes" column.
# You do not need to change these lines if your labels are Yes
# and No.
confusion["Yes", "Yes"] / sum(confusion[, "Yes"])
[1] 0.4901186
# SPECIFICITY: of the people who did not have the outcome, the
# proportion the rule correctly left alone.
confusion["No", "No"] / sum(confusion[, "No"])
[1] 0.6761134
  • Sensitivity is 0.49: of the 253 people who actually had high blood pressure, the rule caught 124, or 49%.
  • Specificity is 0.68: of the 247 people who did not, the rule correctly left 167 alone, or 68%.

The rule misses about half of the people with high blood pressure, so on its own, BMI category is a weak screening rule for it.

TipWith your own data

Write your rule in the first ifelse() and your outcome in the second. Comparisons you can use include == (equal to), >= (at least), > (greater than), <= (at most), and < (less than). If your data already have a predicted column and an actual column, skip the ifelse() lines and put those columns in table(), predictions first.
